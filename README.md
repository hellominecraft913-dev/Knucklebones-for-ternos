# Knucklebones-for-ternos

A remake of the Knucklebones Minigame From Cult Of The Lamb designed for teink devices running TernOS

#How to install

Go to https://ternos.org/ and use the device files menu with your device connected and drop the file bellow into the apps folder

https://github.com/hellominecraft913-dev/Knucklebones-for-ternos/blob/0f1df609ddfa8c6934c0a82e6c609fd76e855dba/knucklebones.bin

#Launch the Game:

Insert the MicroSD card into your XTEINK device and power it on.

Navigate to Apps on the home screen and select Knucklebones.
